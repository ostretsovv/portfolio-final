# Портфолио Виктора Острецова

Адаптивный одностраничный сайт видеомонтажёра с горизонтальными и вертикальными кейсами. Проект собран на React, Next.js и Vinext. Итоговая сборка полностью статическая.

Работы находятся в `app/portfolio-content.ts`. Поле `format` принимает `portrait` или `landscape`. В проект включены два существующих кейса и два пустых шаблона для заполнения.

Подробная инструкция по замене работ, контактов и публикации находится в `START_HERE_RU.md`.

## Команды

```bash
npm install
npm run build
```

После сборки готовые файлы находятся в `dist/client`.
