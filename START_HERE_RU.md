# Начни здесь

Сайт уже собран и адаптирован для компьютеров и телефонов. Навигация, плавная прокрутка, анимации, карточки и окно просмотра работ работают без дополнительных настроек.

## Что нужно заменить перед публичным запуском

### 1. Telegram или почта

Открой `app/portfolio-content.ts` и заполни одно или оба поля:

```ts
telegramUrl: "https://t.me/твой_username",
email: "твоя_почта@example.com",
```

Если поле пустое, соответствующая кнопка не показывается. Сейчас вместо контакта работает кнопка, которая копирует заготовку сообщения.

### 2. Видео

Положи файлы MP4 в папку `public/videos`. Затем в `app/portfolio-content.ts` укажи путь:

```ts
videoUrl: "/videos/work-01.mp4",
```

Вместо файла можно вставить обычную ссылку YouTube. Ссылка автоматически откроется во встроенном проигрывателе.

### 3. Обложки

Положи изображения JPG, PNG или WebP в папку `public/posters`. Затем укажи путь:

```ts
posterUrl: "/posters/work-01.webp",
```

Обложка используется для локального видео до начала воспроизведения.

### 4. Названия и описания

В том же файле находятся имя, главный текст, блок обо мне и массив `works`. Каждый объект внутри `works` является одной карточкой.

Чтобы добавить работу, скопируй один объект и поменяй его данные. Чтобы убрать работу, удали объект целиком. Пустые карточки сайт не создаёт. Сетка автоматически перестраивается под любое количество работ.

## Как пересобрать сайт после изменений

На компьютере должны быть установлены Node.js версии 22 или новее и npm.

1. Открой Терминал.

2. Перетащи папку с исходниками в окно Терминала после команды `cd `.

3. Выполни `npm install`.

4. Выполни `npm run build`.

5. Готовая версия появится в папке `dist/client`.

## Что загружать на хостинг

Для первой публикации используй содержимое папки `ready-to-upload` из итогового архива. Исходники находятся рядом в папке `source`.

После изменения исходников загружай на хостинг новое содержимое `dist/client`.
