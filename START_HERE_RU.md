# Как добавлять работы

Все кейсы редактируются в одном файле: `app/portfolio-content.ts`, в массиве `works`.
Два существующих ролика и их обложки сохранены. Добавлены два шаблона:

| ID | Карточка | Формат |
| --- | --- | --- |
| `work-03` | Горизонтальный проект | `landscape`, 16:9 |
| `work-04` | Вертикальный проект | `portrait`, 9:16 |

Пока `videoUrl` пустой, карточка показывает «Скоро», а окно просмотра показывает «Видео скоро». Несуществующие файлы не запрашиваются. Когда укажешь путь к ролику, появится проигрыватель. Если шаблон пока не нужен на сайте, удали его объект из массива `works` целиком.

## Заполнить горизонтальный кейс

1. Положи видео в `public/videos/work-03.mp4`.
2. Положи обложку в `public/posters/work-03.webp`. Подходят также JPG и PNG, расширение в пути должно совпадать с файлом.
3. Открой `app/portfolio-content.ts`, найди объект с `id: "work-03"` и заполни его:

```ts
{
  id: "work-03",
  format: "landscape",
  title: "Название твоей работы",
  category: "Категория проекта",
  duration: "2:15",
  description: "Опиши задачу, свой подход и результат.",
  details: ["Монтаж", "Цвет", "Саунд-дизайн"],
  videoUrl: "/videos/work-03.mp4",
  posterUrl: "/posters/work-03.webp",
  tone: "blue",
},
```

Значения выше являются примером. Укажи свои название, длительность и выполненные задачи.

Для вертикального кейса заполни `work-04` таким же образом и оставь `format: "portrait"`.

## Добавлять следующие кейсы

Скопируй целиком любой объект внутри `works`, вставь рядом и задай уникальный `id`, например `work-05`. Между объектами оставляй запятые. Внешние скобки массива `works = [...]` не удаляй.

- `format: "portrait"` добавляет карточку в вертикальные работы.
- `format: "landscape"` добавляет карточку в горизонтальные работы.
- Если поле `format` пропущено, работа считается вертикальной, как в прежней версии.
- Сетка сама перестраивается под количество работ. Пустая группа не отображается.
- Порядок внутри каждой группы соответствует порядку объектов в `works`.
- Первый объект массива показывается также в обложке сайта. Он может быть любого из двух форматов.
- `tone` задаёт фон до загрузки обложки: `violet`, `sand`, `blue` или `rose`.
- `duration` можно оставить пустым. Фактическое время показывается в самом проигрывателе.
- `details` можно оставить пустым массивом `[]`.

## Видео и обложки

Для локальных видео используй MP4 с H.264 и звуком AAC. Имена файлов лучше писать латиницей без пробелов, например `interview-01.mp4`.

Папка файла: `public/videos/interview-01.mp4`.
Путь в настройках: `/videos/interview-01.mp4`. Слово `public` в URL не нужно.

Горизонтальные карточки имеют пропорции 16:9. Горизонтальное превью и все видео в проигрывателе вписываются целиком без растягивания. Для роликов с другими пропорциями внутри проигрывателя могут появиться поля. Вертикальная карточка сохраняет прежнее оформление, поэтому её фон может немного обрезаться, но при открытии виден полный кадр.

Для обложки выбирай изображение того же формата, что и ролик. Обложка отображается до запуска превью и когда браузер ограничивает автовоспроизведение. Превью играет без звука и повторяет первые 6 секунд. Видео вне видимой области, на скрытой вкладке и под открытым просмотром приостанавливаются. Полный ролик запускает посетитель в проигрывателе.

Можно также использовать обычную ссылку YouTube в `videoUrl`. Собственная обложка из `posterUrl` имеет приоритет над автоматической. `format` выбирается вручную и для внешних видео.

## Проверить на своём компьютере

Открой Terminal в папке проекта, где находится `package.json`. Нужен Node.js 22.13 или новее.

При первой установке выполни:

```bash
npm install
```

Запусти сайт:

```bash
npm run dev
```

Открой адрес, который покажет Terminal. Проверь оба формата, обложки, звук и описание. Останови сервер сочетанием Control + C.

Собери сайт:

```bash
npm run build
```

Сборка создаёт папку `dist/client`. Команда работает и без GNU timeout в macOS.

## Обновить свой репозиторий

Если заменяешь файлы в существующем проекте, перенеси файлы из архива исправления с сохранением путей. Не заменяй папки целиком. В архиве исправления нет видео и обложек.

Добавь изменённые файлы:

```bash
git add app/page.tsx app/globals.css app/portfolio-content.ts scripts/build-verified.sh START_HERE_RU.md README.md tests/rendered-html.test.mjs tests/ui-components.test.mjs
```

Если добавлял новые видео или обложки, добавь и их. Например:

```bash
git add public/videos/work-03.mp4 public/posters/work-03.webp
```

Создай коммит:

```bash
git commit -m "Support landscape and portrait portfolio cases"
```

Отправь изменения:

```bash
git push
```

Для имеющегося проекта с подключённым репозиторием Vercel соберёт обновление после отправки. Настройки сборки этого проекта: команда `npm run build`, выходная папка `dist/client`. Секретные ключи для сайта не требуются.

## Контакты и тексты

Имя, вводный текст, блок «Обо мне», Telegram и почта находятся в `siteContent` в том же файле `app/portfolio-content.ts`. Пустое поле почты или Telegram скрывает соответствующую кнопку.
